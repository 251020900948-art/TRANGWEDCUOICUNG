Chào mừng đến với trang web của tôi!

Đây là trang chủ của dự án cuối kỳ môn Xây dựng Web. Trang web này được xây dựng bằng HTML ngữ nghĩa và CSS thuần, tuân thủ các quy chuẩn về khả năng tiếp cận (Accessibility).

Trong môn học này, tôi đã được học về cấu trúc tài liệu HTML, cách sử dụng các thẻ ngữ nghĩa, áp dụng Flexbox, Grid, cũng như các yếu tố như Box Model (margin, padding, border) để làm trang web đẹp mắt và thân thiện với người dùng hơn.
